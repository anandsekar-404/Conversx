How to Obtain Your API Key

⚡ OpenAI API Key Setup

  1. Open the official OpenAI Developer Platform (platform.openai.com/api-keys).
  2. Sign in or create your OpenAI developer account.
  3. Navigate to API keys in the left dashboard menu.
  4. Click Create new secret key and give it a descriptive name (e.g., "ConversX Coach").
  5. Copy the generated key immediately (starts with sk-).
  6. Return to ConversX and paste it into the OpenAI API Key field.

✨ Google Gemini API Key Setup

  1. Open the official Google AI Studio Dashboard (aistudio.google.com/app/apikey).
  2. Sign in with your Google Account.
  3. Click Get API key in the top navigation.
  4. Click Create API key (choose an existing project or create a free project).
  5. Copy your new API key (starts with AIzaSy).
  6. Return to ConversX and paste it into the Google Gemini field.
Important: You must manually copy and paste your key. ConversX will never attempt to extract credentials automatically.
